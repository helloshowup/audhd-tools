Drop the Gemini pictures in this folder.

Pictures can be added as .webp (preprocessed for mobile performance, 1024x1024 @ q85)
or as .png. Each picture's base file name must match the FILE line of its block in
gemini-prompts.txt (for example barbell-bench-press-start.webp or barbell-bench-press-start.png).
The app serves the .webp version with automatic fallback to .png. Until a picture is
added, the slot shows "Picture not added yet" with the file name it is waiting for.
